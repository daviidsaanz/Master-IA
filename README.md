# Artificial Intelligence Projects Repository

---

## 📖 Overview

This repository contains a collection of **Artificial Intelligence projects**, divided into three main categories:

1. **Classical AI Algorithms**  
   - Includes implementations of **A\*** and **Genetic Algorithms**.  
   - Focused on pathfinding, optimization, and algorithmic problem solving.

2. **Classic Machine Learning**  
   - Projects using popular Python libraries such as **Scikit-learn**, **NumPy**, **Matplotlib**, and **Pandas**.  
   - Covers tasks like classification, regression, and data visualization.

3. **Deep Learning**  
   - Includes neural network implementations using **PyTorch**, **NumPy**, and **Pandas**.  
   - Contains a deep learning project implemented **from scratch using only NumPy**.  
   - Covers tasks like image recognition, pattern recognition, predictions and neural networks.

---

## 🛠 Technologies & Libraries

- **Classical AI**: Python  
- **Machine Learning**: scikit-learn, NumPy, Matplotlib, Pandas  
- **Deep Learning**: PyTorch, NumPy, Pandas  

---

## ⚡ Installation

To run these projects, you can create a virtual environment and install the required libraries:

```bash
# Create a virtual environment (optional but recommended)
python3 -m venv venv
source venv/bin/activate  # Linux / macOS
venv\Scripts\activate     # Windows

# Install required libraries
pip install numpy pandas matplotlib scikit-learn torch torchvision
```
